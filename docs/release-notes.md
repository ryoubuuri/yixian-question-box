第一版可安装测试包：题库优先，AI 兜底。

- 中文离线 OCR、悬浮窗截图、区域框选与复用。
- 导入 CSV / XLSX / JSONL，预览并显示坏行；结构化保存题干、选项、答案、解析、来源。
- 保留数字、公式和否定词；按选项正文重映射答案字母；展示冲突而非自动覆盖。
- 无 Key 可用本地题库；未命中时调用用户配置的兼容 Chat Completions 接口，结果标为 AI 参考。
- 包名 com.yixian.questionbox，Android 7.0 及以上；首次使用需授予悬浮窗和本轮屏幕采集权限。

这是早期测试版。OCR 断行、公式及复杂页面需要人工核对；多题页面建议框选一道题。没有接入第三方产品私有接口或题库。

下载 APK 后可通过 SHA256SUMS.txt 核验。CI 发布后清理构建目录，不上传 Actions 构建产物。
